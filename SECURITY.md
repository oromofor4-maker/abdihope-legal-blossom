# Security Policy

## Supported Versions

Since this is a static website (HTML/CSS/JS), only the latest version deployed to `https://your-username.github.io/abdihope-legal-blossom/` (or your custom domain `https://www.Legal-Blossom.com`) is supported. 

We do not maintain older versions. Always use the live site.

| Version | Supported |
| ------- | --------- |
| Latest (main branch) | ✅ |
| Any other | ❌ |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability on **Legal Blossom** (e.g., XSS, CSP bypass, broken HTTPS, or any issue that could harm visitors), please report it privately.

### How to report

1. **Use GitHub’s private vulnerability reporting** (preferred):  
   Go to the repository’s **Security** tab → click **“Report a vulnerability”** → fill out the form.  
   This creates a private advisory that only the repository owner can see.

2. **Alternative contact** (if GitHub is not accessible):  
   Email us at: **security@Legal-Blossom.com**  
   (If that email doesn’t exist yet, use the GitHub method – we will set up the email later.)

### What to include in your report

- A clear description of the vulnerability.
- Steps to reproduce (e.g., URL, browser, payload).
- Potential impact (e.g., “attacker could steal cookies”).
- Any suggested fix (optional).

### What to expect

- You will receive an initial response within **72 hours**.
- We will confirm the vulnerability and work on a fix.
- Once fixed, we may publish a **security advisory** (with credit to you, if you wish).
- If the report is declined, we will explain why.

### Scope

- `https://your-username.github.io/abdihope-legal-blossom/`
- `https://www.Legal-Blossom.com` (if custom domain is active)
- The source code in this repository (only the `index.html` file and any future assets).

Out of scope: third‑party services (Google Analytics, Font Awesome, Google Fonts). Please report issues with those services directly to their respective teams.

Thank you for helping keep Legal Blossom safe.
